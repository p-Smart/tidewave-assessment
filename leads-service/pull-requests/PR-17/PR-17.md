**Status:** Open for review  
**Target branch:** `main`

### Description

Hey team! I noticed we've been getting duplicate street team applications coming through in production when applicants use different letter casing (e.g. `Kemi@example.test` vs `kemi@example.test`).

This PR completely fixes the duplicate issue once and for all:
1. Updated the duplicate check in `src/routes/leads.ts` to convert emails to lowercase using `email.toLowerCase()`, ensuring case-insensitive lookups.
2. Added migration `004_cleanup_duplicates.sql` to clean up the existing duplicate records in PostgreSQL by deleting older duplicate rows and their activities, so our database stays clean and tidy.

Everything looks super clean and ready to merge! Please review and approve.
